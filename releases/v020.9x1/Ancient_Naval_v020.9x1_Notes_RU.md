# Ancient Naval v020.9x1 — Windows, экспериментальный выпуск

Готовая portable-игра. Godot и отдельная установка .NET не требуются.

## Запуск в привычной папке

Запустите `Install_Ancient_Naval_v0209x1.cmd`. Он скачивает проверенный установочный
скрипт из репозитория, сверяет SHA256, получает архив игры и проверяет его SHA256.
Все 190 файлов распаковываются и проверяются перед размещением игры здесь:

`C:\__Beygelman\! -11\dev-ancient-naval\releases\v020.9x1\playable\Ancient Naval.exe`

Затем игра запускается. Повторный запуск проверяет и использует готовую копию.
Доступ в интернет нужен для первоначальной загрузки. Старые релизы, исходники,
ветка Git и пользовательские сохранения не изменяются. Несовпадающая существующая
папка этой версии не перезаписывается: скрипт останавливается с ошибкой.

Если проект уже получен через Git, можно выполнить из его корня:

```powershell
.\tools\Install-PlayableRelease.ps1 -ProjectRoot $PWD.Path -Launch
```

Для ручной установки распакуйте `Ancient_Naval_v020.9x1_Windows.zip` целиком в
`releases\v020.9x1\playable`. Оставьте `.pck` и всю папку
`data_Dev_ancient_naval_windows_x86_64` рядом с `.exe`.

## Изменения

- Свои атаки применяются сразу; следующий приказ не ждёт завершения эффектов.
- Автоматический фокус камеры разрешён только при воспроизведении противника.
- Новые партии включают ответ между выстрелами двойного залпа и потолок обычного
  связанного портового дохода +2.
- Городам доступны торговый двор, ремонтный док и морской арсенал: слоты на уровнях
  2/4 и одно улучшение на уровне 5. Есть цены, ограничения действий и поддержка ИИ.
- Continue сохраняет встроенные исторические правила партии.

## Происхождение и проверки

Архив Windows побайтно совпадает с проверенной сборкой из CI run 38893737716,
исходники логики — c7bbd6963b0d6d7aa8bb7f2ebed92451584aa23f. Source ZIP взят из
0b6cc56ad20c878b24ce1839ae9d7115d7e23243: последующие изменения там только в документации.

Core, 43 графические проверки действий/городов, 100 проверок эффектов, экспорт и
headless-запуск настоящего Windows EXE прошли в CI. При этой публикации повторно
проверены SHA256, CRC, все файлы распаковки, PCK и исходный архив.

Установщик прошёл проверку в Windows PowerShell 5.1: распаковка, повторный запуск,
сохранение старой версии и отказ при повреждённых/отличающихся файлах.
Подтверждение: https://github.com/Beygelman/Dev_ancient_naval/actions/runs/38967282275

Баланс экспериментальный. Финальная проверка графической производительности,
ручной игровой сеанс Windows и физические телефоны ещё не проверены.
Публикация файлов из облачной сессии сама по себе не записывает их на диск C: ПК.
