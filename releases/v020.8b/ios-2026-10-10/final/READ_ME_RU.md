# Ancient Naval v020.8b — iPhone, 10 октября 2026

Начните с **INSTALL-iPHONE-RU.md**. Для Windows используйте
**Ancient_Naval_v020.8b_iPhone_UNSIGNED.ipa** и AltStore Classic/AltServer:
приложение подписывается вашим Apple Account. Собственный Mac не нужен.
Нельзя установить неподписанный IPA простым открытием файла на телефоне.

Сборка iOS и запуск главного меню в симуляторе iPhone 16 проверены.
Установка, управление и производительность на настоящем iPhone ещё не проверены.
Поддержка C# iOS в Godot экспериментальная. Это тот же v020.8b; правила игры
не изменены. Исторические Windows-архивы сохранены.

- iOS_Xcode_UNSIGNED.zip — полный проект для Mac/Xcode, с PCK и библиотеками.
  Большой ZIP сохранён локально; в обычный Git не загружен.
- iOS_SOURCE_HANDOFF.zip — воспроизводимый архив исходников, не установщик.
- IOS-PORT-REPORT.md — выполненные проверки и оставшиеся ограничения.
- IOS-PACKAGE-VALIDATION.json — проверка состава готового IPA.
- SHA256-iOS.txt — неизменённые контрольные суммы облачных IPA/Xcode ZIP.
- SHA256-DELIVERY.txt — контрольные суммы всех остальных файлов передачи
  и облачных архивов; относительные пути считаются от родительской папки
  ios-2026-10-10.

Папка final содержит итоговый вариант. Ранний прототип в родительской папке
сохранён для истории; для установки выбирайте IPA именно из final.
