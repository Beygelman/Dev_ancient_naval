# v020.9x1 — experimental build, 16 October 2026

## Permanent interaction behavior
Player commands commit all gameplay results immediately. Visual effects run with
commands available; issuing the next legal command settles remaining visuals.
Own orders and encounters do not automatically move the camera. Opponent actions
remain staged and ordered; only their replay may request automatic action focus.
Manual map navigation, initial fitting and voyage introduction remain separate.

Sinking durations are 0.9 seconds for ordinary hulls, 1.15 for balloons and 1.3
for Motherships, with an additional animation-rate adjustment for combat effects.
Crashes/collapse are committed once, independent of skipping or continuing a save.

## Saved experiments
New voyages enable these independently in data/balance.json. Continue reads the
embedded rules instead of replacing them with the current catalog.

| Rule | New voyage | Absent historical field |
|---|---|---|
| counterBetweenSalvoShots | true | false: two shots before the one reply |
| ports.connectedCityIncomeCap | 2 | 0: no ceiling on connected-city income |
| infrastructure.enabled | true | false: no facility bonuses or commands |

The salvo order is first shot, surviving target's single reply, second shot if
the attacker remains alive. It covers ship and town targets and Mothership double
attacks. Both attacks are reserved when choosing a double salvo. Existing
equal-double-salvo damage remains; applied damage is still capped by target HP.
Single shots, hull stats, prices, movement and Restoration are unchanged.

The trade cap limits ordinary network income, not the number of connected ports.
Lighthouses remain relays, not paying cities. A working trade yard adds its own
bonus. Town base income remains independent. Gross income, receipts and displayed
port income share the same calculation.

## City facility prototype
Use the city's infrastructure command to open a native scrollable paper. The
footer stays outside scrolling content; choices support pointer/touch and EN/UK/NL.

| Item | Prototype value |
|---|---|
| Facility slots | First at level 2, second at level 4 |
| Install | 6 Thors |
| Replace | 6 + 3 Thors; removes the replaced bonus |
| Improve | 6 Thors at level 5; one installed facility, doubled bonus |
| Trade yard | +2 trade income only with a connected friendly port partner |
| Repair dock | +2 active repair HP for one adjacent ship that did not move |
| Naval arsenal | +2 shared fleet capacity |

No duplicate facility types in one city. Installation, replacement and improvement
consume the city's work for the turn. Removing an improved facility removes its
improvement. Dock service consumes the ship's remaining actions and that city's
work; it cannot provide repeated free repairs to a firing group. Passive healing
is unchanged. Improved bonuses are +4 instead of +2.

Cities retain normal hull unlocks. Capacity loss does not delete hulls; the
existing capacity check prevents new construction. Defeated facilities give no
bonus; capture transfers the city's installed objects. AI selects infrastructure
using its own assets and observed threats, pays the same prices, and avoids
replacement churn.

build. Test equal budgets and fleet capacity in open sea, choke points and split
