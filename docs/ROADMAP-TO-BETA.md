Состояние: 28 сентября 2026, игровая альфа **0.06**.

## Критерий готовой беты

Новая партия на генерируемой карте → разведка → производство → бой →
победа/поражение. Партию можно сохранить, закрыть приложение и продолжить.
Все действия доступны пальцем на целевом Android, без зависания ИИ и потери прогресса.

Переход между бесконечными секторами остаётся отдельным этапом после одиночной
Beta 0.1. Финальное художественное оформление не требуется для проверки игрового цикла.
