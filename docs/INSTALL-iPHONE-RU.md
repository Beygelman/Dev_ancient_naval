# Ancient Naval v020.8b — установка на iPhone 16

Порт подготовлен для горизонтального экрана и сенсорного управления. Для установки нужен **Mac с Xcode**: проект необходимо собрать и подписать вашим Apple Account. Обычный ZIP или неподписанный IPA нельзя установить, просто открыв его на iPhone. Godot требует macOS и Xcode для экспорта iOS; поддержка C# на iOS имеет экспериментальный статус. [Требования Godot](https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_ios.html).

**Текущий статус:** подготовлены исходники, сенсорное управление и процедура сборки. Нативный экспорт, подпись и запуск именно на iPhone ещё не проверены. Проверки на Windows не являются проверками устройства iOS.

## 1. Подготовьте Mac

Установите:

- Полный **Xcode** из Mac App Store, подходящий для версии iOS вашего телефона. Одних Command Line Tools недостаточно. Откройте Xcode, завершите первый запуск и установите предложенные компоненты iOS.
- **Godot 4.7.2 .NET для macOS**, именно вариант .NET. В Godot откройте **Editor → Manage Export Templates** и установите шаблоны экспорта той же версии **4.7.2 .NET**.
- **.NET SDK 8.0.425** для архитектуры вашего Mac.
- **Python 3**.

Скопируйте на Mac полный исходный проект либо получите его из [репозитория Ancient Naval](https://github.com/Beygelman/Dev_ancient_naval). Windows-пакет с EXE для этого не подходит.

Если Xcode не находится автоматически, в Терминале укажите установленное приложение:

```bash
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
xcodebuild -version
dotnet --list-sdks
python3 --version
```

## 2. Соберите проект iOS

В Терминале перейдите в папку исходников. Укажите фактический путь к исполняемому файлу Godot внутри приложения:

```bash
GODOT_BIN="/Applications/Godot_mono.app/Contents/MacOS/Godot" \
IOS_BUNDLE_ID="com.beygelman.ancientnaval.personal" \
bash tools/Build-iOS.sh
```

Замените пример `IOS_BUNDLE_ID` своим уникальным идентификатором, если Xcode сообщает, что он уже занят. Сохраняйте этот идентификатор при последующих установках.

Скрипт создаёт новую отдельную папку, не заменяя исходники и предыдущие сборки. Он экспортирует игру и проверяет сборку Xcode без подписи. В конце выводит путь к `AncientNaval.xcodeproj`. Откройте его в Xcode. **Сохраните всю соседнюю папку `xcode`**, включая PCK и библиотеки: одного файла проекта недостаточно.

Получаемый `Ancient_Naval_v020.8b_iOS_Xcode_UNSIGNED.zip` — полный проект Xcode, **не готовое подписанное приложение**. Значение Team `AAAAAAAAAA` в подготовительном экспорте является техническим заполнителем; перед запуском выберите настоящую команду в Xcode.

Если скрипт завершился ошибкой, сохраните `import.log`, `export.log` или `xcode-build.log` из выведенной папки. Не считайте экспорт успешным, пока проверка не завершилась.

## 3. Подпишите своим аккаунтом

1. В Xcode откройте **Settings → Apple Accounts** и войдите в свой Apple Account.
2. В проекте выберите приложение в **TARGETS → Signing & Capabilities**.
3. Включите **Automatically manage signing**.
4. В **Team** выберите свой аккаунт — **Personal Team** для бесплатной личной установки либо вашу команду Apple Developer Program.
5. Проверьте **Bundle Identifier**: он должен быть уникальным и совпадать с выбранным для этой установки.

В **Build Settings → Code Signing Identity** для Debug должна использоваться **Apple Development**. Если после подготовительного экспорта осталось значение `-` (ad-hoc), замените его; заполнитель Team `AAAAAAAAAA` также должен быть заменён настоящей командой. Подготовительная подпись библиотек не является подписью приложения для телефона.

Xcode создаёт необходимые средства подписи для личной команды. Пароль аккаунта, ключи и сертификаты вводятся вами в Xcode; передавать их агенту не требуется. [Подпись приложения в Xcode](https://help.apple.com/xcode/mac/current/en.lproj/dev60b6fbbc7.html).

## 4. Подключите iPhone и установите игру

1. Подключите iPhone 16 к Mac USB-кабелем, разблокируйте телефон и подтвердите **«Доверять этому компьютеру»**.
2. Дождитесь появления телефона в Xcode, при необходимости откройте **Window → Devices and Simulators**.
3. На iPhone включите **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Если пункта пока нет, сначала выполните сопряжение с Xcode или попробуйте запустить приложение из Xcode. Подтвердите перезагрузку и затем включение режима.
4. В верхней панели Xcode выберите свой **физический iPhone 16**, а не симулятор.
5. Нажмите **Run ▶**. Xcode соберёт, подпишет, установит и запустит Ancient Naval.

При запросе доверия разработчику следуйте сообщению iPhone; соответствующий профиль может находиться в **Настройки → Основные → VPN и управление устройством**. Если телефон недоступен как цель запуска, проверьте совместимость установленного Xcode с его версией iOS. [Запуск на устройстве](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices), [режим разработчика](https://developer.apple.com/documentation/xcode/enabling-developer-mode-on-a-device).

## 5. Бесплатная установка и повторный запуск

Для установки на собственный телефон можно использовать бесплатную Personal Team. Её профиль установки истекает через **7 дней**: подключите телефон и снова нажмите Run в Xcode. Не удаляйте приложение ради обновления и сохраняйте тот же Bundle Identifier, чтобы не удалять его данные вручную. [Ограничения личного аккаунта Apple](https://developer.apple.com/help/account/basics/about-your-developer-account).

Для распространения через TestFlight нужен отдельный процесс Apple Developer Program. TestFlight-сборка и ссылка приглашения в этот пакет не входят.

## Альтернатива: подготовка проекта через GitHub Actions

Если сборку исходников удобнее выполнить в облаке:

1. В репозитории откройте **Actions → iOS — unsigned Xcode project** — файл `.github/workflows/ios.yml`.
2. Нажмите **Run workflow**, выберите нужную ветку и уникальный `bundle_id`.
3. Только после успешного выполнения скачайте артефакт **Ancient-Naval-iOS-Xcode-UNSIGNED**.
4. Распакуйте артефакт, затем вложенный ZIP проекта. Сохраните весь комплект `xcode`.
5. На Mac откройте проект и выполните разделы 3–4 этой инструкции.

Облачная задача готовит и проверяет неподписанный проект. Она не устанавливает игру на телефон и не заменяет личную подпись в Xcode. При ошибке сборки доступен артефакт **iOS-build-diagnostics**; наличие исходников или инструкции само по себе не означает успешную сборку.

## Управление и первая проверка

- Играйте горизонтально. Одно короткое касание выбирает объект или действие.
- Перетаскивание одним пальцем двигает карту; два пальца меняют масштаб.
- Удержание на подходящей цели вызывает существующий выбор залпа.
- Свитки и окна прокручиваются собственными жестами; жесты над ними не должны двигать карту.
- Верхняя часть реликвии справа внизу завершает ход; её счётчик переключает объекты с доступными действиями.

После первого запуска проверьте новую игру, сохранение/«Продолжить», касания свитков, масштабирование и возвращение из фона. Отдельно проверьте, что Dynamic Island и нижний индикатор не перекрывают кнопки. Это необходимая проверка на настоящем устройстве, которая пока остаётся невыполненной.
